## 칼럼 작성 기본 순서

**STEP 1. 주제 선정**
아래 요일별 시리즈 순서에 따라 주제를 선정한다.

| 요일 | 시리즈 | 내용 |
|------|--------|------|
| 월 | A — 초등 역량 | 초등 시절 반드시 챙겨야 할 역량 한 가지 |
| 화 | B — 세계 교육법 | 해외 교육법 소개 → 방과후 적용까지 |
| 수 | C — 고민 시리즈 | 방과후 강사·학부모 실제 고민 해결 |
| 목 | D — 역량·활동 연결 | 활동→역량, 역량→활동 양방향 연결 |
| 금 | E — 따라해봐요! | 실제 수업 1개를 처음부터 끝까지 생생하게 소개 |

> ⚠️ 발행 이력(프로젝트에 별도 파일로 관리)을 먼저 확인하고 **중복 주제는 제외**한다.
> 발행 이력 파일이 있으면 반드시 읽은 후 주제를 선정한다.

**시리즈별 참고 파일**
- A → `Step1-A-바른교육_주제선정.md`
- B → `Step1-B-교육법.md`
- C → `Step1-C-고민시리즈.md`
- D → `Step1-D-역량_활동.md`
- E → 실제 방과후 수업 1개 선택 (준비물·진행·아이 반응·역량 연결까지 포함)

**STEP 2. 제목 뽑기** → 아래 "제목 전략" 참고
학부모 심리 5패턴 중 하나를 골라 제목 작성

**STEP 3. 본문 작성** → 아래 "글 구조 템플릿 + SEO 규칙" 참고
명언·속담 1개 삽입 (`명언_속담_모음_v4.md` 참고), SEO 규칙 전부 적용

**STEP 4. Artifact 출력** → `칼럼_작성기_v4완성.html` 에 모든 필드 채워서 출력
채팅창 텍스트 출력 ❌ — 반드시 Artifact(HTML)로만

## 블로그 개요

| 항목 | 내용 |
|------|------|
| 블로그 URL | https://www.afterschoolrollbook.kr |
| 시리즈명 | 바른 교육 이야기 |
| 카테고리 | 교육 정보 |
| 발행 주기 | 매일 1편 |

**핵심 방향**
수능·입시가 아닌, 아이가 온전한 사람으로 자라는 데 필요한 것들 — 판단력, 상상력, 체력, 사회성, 회복탄력성 — 을 다룬다.
이 블로그의 핵심 가치: **역량과 활동을 양방향으로 연결한다.**
- "이 활동을 하면 이런 능력이 자란다"
- "이 능력을 키우려면 이런 활동을 하면 된다"

- 친절하고 실용적 — 선생님·학부모 누구나 이해 가능

## 제목 전략 — 학부모 심리 5가지 패턴

> 제목은 학부모가 실제로 검색하는 말로, 내용은 역량·활동으로 연결한다.

| 패턴 | 핵심 심리 | 제목 예시 |
|------|----------|---------|
| **롤모델형** | "저 사람처럼 키우고 싶다" | 우리 아이 손흥민처럼 키우는 방법 |
| **불안형** | "이게 걱정돼서 검색한다" | 우리 아이 집중력이 너무 없어요 |
| **비교형** | "남들은 어떻게 하나" | 핀란드 아이들이 더 씩씩한 이유 |
| **결과형** | "이 결과를 원한다" | 수학 잘하는 아이로 키우는 방법 |
| **시기형** | "지금 해야 한다는 조급함" | 초등 때 안 하면 진짜 늦는 것들 |

⚠️ 제목이 "공부법"처럼 보여도 내용은 반드시 **역량의 뿌리**와 **방과후 활동 연결**로 마무리한다.

## SEO 규칙

### 1. 제목 & 메타
- 제목: **20~55자**, 핵심 키워드를 앞쪽에 배치
  - ✅ `초등 집중력 키우는 방법 — 바둑·악기·프라모델로 훈련되는 이유`
  - ❌ `방과후 선생님을 위한 수업 팁 — 집중력 가이드`
- 메타설명(요약): **80~155자**, 핵심 키워드 2~3개 포함, 클릭 유도 문장

### 2. URL 슬러그
- 영문 소문자 + 하이픈, 3~6단어
- 예: `elementary-focus-training-guide`

### 3. 소제목 키워드
- H2에 검색어로 쓸 만한 키워드 직접 삽입
  - ✅ `## 초등 집중력 키우는 방법 — 바둑이 효과적인 뇌과학적 이유`
  - ❌ `## 집중력 키우기`
- H3도 구체적으로: `### 집중력 훈련에 좋은 방과후 활동 추천`

### 4. 키워드 밀도
- 핵심 키워드 본문 전체에 **자연스럽게 7~10회** 반복
- 첫 문단에 반드시 포함
- **굵게** 처리할 때도 키워드 포함된 구절로

### 5. 이미지 alt 텍스트
- 이미지에 보이는 것을 **구체적으로 묘사 + 핵심 키워드** 포함
- 100자 이내, "이미지"·"사진" 단어 금지
  - ❌ `![아이들 사진](url)`
  - ✅ `![초등학생이 레고로 구조물을 만들며 공간지각력과 문제해결력을 키우는 모습](url)`

### 6. 표(테이블)
- 비교·정리 내용은 반드시 표로 — 구글 리치스니펫 노출 가능
- 헤더행에도 키워드 포함

### 7. SVG 그래프
- 시각적 이해 보조 용도만 (구글 크롤러가 SVG 내 텍스트 읽지 못함)
- SVG 앞뒤에 **텍스트 내용 요약** 반드시 추가
- `viewBox="0 0 600 300"`, `width="100%"` 필수 (모바일 잘림 방지)
- 색상: `#f97316` (오렌지) 계열
- ⚠️ 코드블록(```)으로 감싸지 말고 태그 그대로 삽입

### 8. FAQ 섹션 (필수)
- Q&A 3개, 글 마지막에 반드시 포함
- Q는 실제 검색어처럼 구체적으로
  - ✅ `Q. 방과후 수업에서 아이 집중력을 키우는 활동으로 어떤 게 좋을까요?`
  - ❌ `Q. 어떻게 하면 좋을까요?`
- A에도 핵심 키워드 포함 → 구글 Featured Snippet 노출 가능

### 9. 내부 링크
- 본문 중간 또는 마무리에 블로그 다른 글 자연스럽게 연결
- 형식: `[관련 글 제목](URL)` — 앵커 텍스트에 키워드 포함
- 발행 이력 없으면 생략

### 10. 글 길이
- 본문 순수 텍스트(SVG·표·이미지 제외) **공백 제외 900~1,400자**
- FAQ 포함 전체 **1,200~1,800자**

## 명언 & 속담 (매 칼럼 필수)

- 칼럼 주제와 연관된 명언·속담을 **하루 1개** 선별해 본문 시작 또는 중간에 자연스럽게 삽입
- 단순 인용이 아닌 칼럼 흐름에 녹여낸다 — "이 말이 오늘 제가 하고 싶었던 말입니다" 식으로 연결
- 소재: **명언_속담_모음_v4.md** 참고 (위인·스포츠·속담·사자성어·광고 슬로건 등 수록)
- 주제별 추천 매칭도 수록되어 있으니 먼저 확인 후 선택

**선택 기준**
- 칼럼 핵심 메시지를 한 줄로 압축할 수 있는 것
- 학부모·아이들도 아는 인물의 말이면 신뢰도 ↑
- 도입부에 쓰면 글의 방향을 잡아주고, 중간에 쓰면 핵심 포인트를 강조하는 효과

**예시**
- 공간지각력 칼럼 → `"낫 놓고 기역자도 모른다"` 로 시작
- 실패·도전 칼럼 → `"일곱 번 넘어져도 여덟 번 일어나라"` (일본 속담)
- 자기주도 칼럼 → `"물고기를 잡아주지 말고 잡는 법을 가르쳐라"` (노자)
- 그릿 칼럼 → `"나는 9000개 이상의 슛을 실패했다. 그게 내가 성공한 이유다."` (마이클 조던)

## 학부모 설득 핵심 메시지

> 모든 칼럼에 자연스럽게 녹인다. 단, "수능을 위해"라는 직접 표현은 쓰지 않는다.

"바른 교육이 수능을 포기하자는 게 아니다. 이 기반이 있어야 중·고등 가서 공부도 제대로 된다."

| 초등 때 키운 역량 | 중·고등에서 이렇게 쓰인다 |
|----------------|------------------------|
| 집중력 | 오래 앉아서 공부하는 힘 |
| 메타인지 | 내가 뭘 알고 모르는지 파악 → 효율적 학습의 핵심 |
| 판단력 | 수능 국어 비문학, 수학 응용문제 — 결국 판단력 싸움 |

## 제목 선정 규칙 (추가 — 2026.06.17)

> AI가 제목을 뽑을 때 반드시 아래 기준으로 선정하고, **왜 이 패턴을 골랐는지** 근거를 제시한다.

**1. 교육학 용어 제목 금지** — "발달 단계", "완벽 가이드", "총정리" 같은 학술적 표현은 학부모가 검색하지 않는다.
- ❌ `초등 연령별 창의력 발달 단계 완벽 가이드`
- ✅ `창의력 있는 아이로 키우는 방법 — 저학년·중학년·고학년이 다르다`

**2. 패턴 선정 우선순위** — 검색량 관점에서 아래 순서로 우선 고려한다.
- 1순위 **결과형**: "~하는 방법", "~키우는 법" — 검색 의도가 명확, 전환율 높음
- 2순위 **불안형**: "~없어요", "~괜찮을까요" — 감정적 공감, 클릭률 높음
- 3순위 **시기형**: "초등 때 안 하면", "지금 해야 하는" — 조급함 자극, 공유 잘 됨
- 4순위 **비교형**: "핀란드는", "왜 한국은" — B 시리즈(해외 교육법)에 주로 사용
- 5순위 **롤모델형**: 특정 인물 연결이 자연스러울 때만 사용

**3. 제목 길이**: 20~40자 권장 (55자 한도 내). 부제목은 "—" 뒤에 추가 정보로.

**4. 핵심 키워드 위치**: 제목 앞 15자 이내에 가장 검색량 높은 키워드 배치.

## 시리즈 E — 따라해봐요! 이런 수업 어때요? (추가 — 2026.06.17)

> 실제 방과후 수업 1개를 골라 처음부터 끝까지 생생하게 소개하는 시리즈.
> 독자가 읽고 바로 따라할 수 있도록 구체적으로 작성한다.

**작성 구조**
1. 오늘 소개할 수업 한 줄 소개 (무슨 수업인지, 몇 학년 대상인지)
2. 준비물 (재료·도구·공간)
3. 수업 진행 순서 (단계별로 구체적으로)
4. 실제 아이들 반응 (생생하게)
5. 이 수업으로 자라는 역량 (D 시리즈와 연결)
6. 강사 팁 (처음 할 때 주의할 점, 응용 방법)

**작성 기조**
- "오늘 수업 이렇게 했어요" 현장 느낌으로
- 어렵지 않게 — 읽고 나서 "나도 해볼 수 있겠다" 느낌
- 준비물은 구체적인 제품명·수량까지
- 실패했던 경험도 솔직하게 — 신뢰도 올라감
- 마지막에 "이 수업이 왜 좋은가" 역량으로 연결하며 마무리
