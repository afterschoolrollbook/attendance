## 교육법 통합 목록 (칼럼 소재 및 수업 설계 참고)

> 📌 **활용 방법**
> - 칼럼 주제로 직접 활용하거나, 본문 내 수업 활동 예시로 자연스럽게 녹여 사용한다
> - "연결 역량"을 보고 태그 축 1 역량 태그를 붙인다
> - C섹션 "세계는 이렇게 가르친다" 시리즈 소재로 활용할 수 있다

### 🌍 해외 교육법 — 한국에선 아직 낯선 것들

| 교육법 | 나라 | 핵심 개념 | 연결 역량 | 한국 현실 |
|--------|------|----------|---------|---------|
| **루브 골드버그 머신** | 미국 | 단순한 결과를 복잡하게 돌아가는 장치로 만들기 | 문제해결력, 공학적사고, 절차적사고, 협동심 | 일부 메이커 교육에서만, 거의 없음 |
| **숲 학교(Forest School)** | 덴마크·독일 | 교실 없이 숲에서 배움 — 자연이 교과서 | 오감발달, 과학적호기심, 실패내성, 신체조절능력 | 독일 2000개, 한국은 거의 전무 |
| **언스쿨링(Unschooling)** | 미국·유럽 | 커리큘럼 없이 아이가 원하는 것만 배움 | 내적동기, 자기주도, 호기심, 자기조절력 | 한국은 제도적으로 거의 불가 |
| **아고라 스쿨** | 네덜란드 | 교사도 교과서도 시험도 없음 — 완전 자기주도 | 자기주도, 기획력, 문제해결력, 내적동기 | 한국엔 개념 자체가 생소 |
| **철학 교육(P4C)** | 미국·프랑스 | 초등부터 "왜 살아야 해?" 같은 질문을 토론 | 비판적사고, 질문력, 판단력, 의사소통 | 한국은 중고등도 거의 없음 |
| **비경쟁 체육** | 핀란드 | 1등 없이 모두가 성공하는 체육 수업 | 자신감, 협동심, 체력, 심리적안정감 | 한국은 무조건 등수·경쟁 |
| **감사 일기·긍정심리 교육** | 미국·호주 | 매일 감사한 것 3가지 쓰기 — 행복 근육 키우기 | 긍정적사고, 정서조절, 메타인지, 심리적안정감 | 한국엔 "쓸데없는 것"으로 취급 |
| **코딩+언플러그드** | 에스토니아 | 컴퓨터 없이 몸으로 알고리즘 이해 | 절차적사고, 논리력, 코딩적사고, 신체표현력 | 한국은 코딩=모니터 앞에 앉기 |
| **뮤지컬 통합교육** | 미국 | 수학·역사·과학을 뮤지컬로 배움 | 표현력, 음악감수성, 융합적사고, 자신감 | 한국은 예체능과 교과가 완전 분리 |
| **실패 축하 문화(Failure Parties)** | 실리콘밸리 | 실패를 발표하고 박수치는 수업 | 실패내성, 그릿, 자기표현력, 회복탄력성 | 한국은 실패=창피 |
| **월드스쿨링** | 글로벌 | 여행하면서 세계 자체가 학교 | 융합적사고, 오감발달, 적응력, 공감능력 | 한국은 학교 빠지면 큰일 나는 문화 |
| **수평적 교실(Circle Time)** | 북유럽 | 책상 없애고 원형으로 앉아 동등하게 토론 | 의사소통, 경청능력, 사회성, 자기표현력 | 한국은 교사 앞 일렬 배치 고정 |
| **위험한 놀이·모험놀이** | 북유럽·독일 | 넘어지고 긁히는 경험을 허용하는 놀이 환경 | 균형감각, 신체조절능력, 실패내성, 판단력, 회복탄력성 | 한국은 다칠까봐 전부 금지 |

### 🏫 수업 설계 교육법 — 방과후에 바로 적용 가능한 것들

| 교육법 | 핵심 개념 | 연결 역량 | 방과후 적용 |
|--------|----------|---------|-----------|
| **몬테소리** | 아이 스스로 선택·반복, 교사는 관찰자 | 자기조절력, 내적동기, 소근육발달, 집중력 | 자유 선택 교구, 소근육 활동 |
| **발도르프** | 예술·자연·리듬 중심, 디지털 최소화 | 음악감수성, 미술감각, 리듬감, 심미안 | 공예·목공·수채화·리코더 |
| **프로젝트 학습(PBL)** | 실제 문제를 팀이 해결, 결과물 발표 | 문제해결력, 협동심, 기획력, 발표력 | 주제 탐구·만들기·발표 |
| **거꾸로 학습(플립러닝)** | 개념은 미리, 수업에선 적용·토론 | 자기조절력, 메타인지, 비판적사고 | 영상 예습 후 실습 수업 |
| **소크라테스식 토론** | 질문으로 생각을 끌어내는 방식 | 질문력, 비판적사고, 판단력, 의사소통 | 철학 토론·책 토론 |
| **디자인씽킹** | 공감→문제정의→아이디어→제작→테스트 | 공감능력, 문제해결력, 발명적사고, 협동심 | 창의 문제 해결 수업 |
| **IB(국제바칼로레아)** | 탐구 중심, 개념 이해, 국제적 마인드 | 탐구심, 비판적사고, 메타인지, 질문력 | 탐구질문 중심 수업 |
| **레지오 에밀리아** | 아이의 100가지 언어, 환경이 교사 | 표현력, 관찰력, 자기표현력, 미술감각 | 표현·전시·기록 중심 |
| **STEAM 교육** | 과학·기술·예술·공학·수학 융합 | 융합적사고, 공학적사고, 창의력, 문제해결력 | 코딩+미술, 과학+디자인 |
| **놀이 중심 학습** | 놀이 자체가 학습, 내재적 동기 | 내적동기, 사회성, 창의력, 자기표현력 | 자유놀이·규칙놀이·역할극 |
| **마인드풀니스(명상)** | 집중력·정서조절 훈련 | 집중력, 정서조절, 심리적안정감, 자기조절력 | 수업 시작 5분 명상·호흡 |
| **협동학습(Jigsaw)** | 역할 분담 후 서로 가르치며 배우기 | 협동심, 의사소통, 책임감, 경청능력 | 팀별 전문가 활동 |
| **마인드맵** | 중심 주제에서 생각을 방사형으로 확장 | 사고력확장, 기획력, 메타인지, 문해력 | 글쓰기 전 구조화, 개념 정리 |
| **발명교육(TRIZ)** | 문제를 창의적으로 해결하는 발명 사고법 | 발명적사고, 문제해결력, 창의력, 관찰력 | 생활 속 불편함 찾아 발명품 만들기 |
| **스토리텔링 학습** | 이야기로 개념을 기억하고 전달 | 스토리텔링, 문해력, 표현력, 기억력 | 창작 동화·역할극·그림책 만들기 |
| **메이커 교육** | 직접 만들면서 배우는 학습 | 설계력, 모델링능력, 공학적사고, 협동심 | 3D펜·목공·전자회로·코딩 |
| **메타인지 학습** | 내가 뭘 알고 모르는지 스스로 파악 | 메타인지, 자기조절력, 판단력, 사고력 | "오늘 뭘 배웠어?" 자기 점검 루틴 |
| **숙달 학습(Mastery Learning)** | 이해할 때까지 다음으로 안 넘어감 | 과제집중력, 그릿, 자기조절력, 메타인지 | 개인별 진도 조절 |
| **개별화 학습(Differentiated Instruction)** | 아이마다 다른 수준·속도·방식으로 배움 | 내적동기, 자신감, 자기조절력 | 심화/기본 버전 병행, 선택형 과제 |
| **하브루타** | 짝과 질문·토론하며 함께 배우는 유대인 교육법 | 질문력, 의사소통, 경청능력, 메타인지 | 둘이 짝지어 서로 설명하고 질문하기 |
| **강점 기반 학습(Strength-based)** | 약점 보완보다 강점을 먼저 키우는 방식 | 자신감, 내적동기, 자아존중감 | 아이가 잘하는 것 찾아 더 깊이 파고들기 |
| **경험 학습(Experiential Learning)** | 직접 경험한 것이 가장 오래 기억됨 — 존 듀이 | 탐구심, 관찰력, 문제해결력, 오감발달 | 현장 체험·실험·역할극 |
| **감성 학습(Emotional Learning)** | 감정이 실린 기억은 뇌에 더 강하게 저장됨 | 정서조절, 공감능력, 자아존중감, 심리적안정감 | 감동적인 발표·공연·성공 경험 |
| **게임 기반 학습(Game-Based Learning)** | 게임처럼 재밌으면 도파민 분비 → 기억 강화 | 전략적사고, 집중력, 사회성, 문제해결력 | 보드게임·퀴즈·미션 클리어형 수업 |
| **체험 활동 학습(Hands-on Learning)** | 몸으로 직접 해본 것은 잊어버리지 않음 | 오감발달, 탐구심, 소근육발달, 과제집중력 | 만들기·요리·실험·텃밭 |
| **스토리텔링 기억법(Episodic Memory)** | 스토리·장면으로 기억하면 오래 남는 뇌과학 | 스토리텔링, 기억력, 언어력, 상상력 | 개념을 이야기로 만들어 기억하기 |
| **컴피턴시 기반 교육(CBE)** | 시간이 아닌 능력 달성 여부로 다음 단계 진행 | 자기조절력, 메타인지, 과제집중력, 그릿 | 개인별 미션 클리어 후 다음 단계 |
| **자기 주도 학습(Self-Paced Learning)** | 각자 속도로, 이해하면 바로 다음으로 | 자기조절력, 내적동기, 메타인지 | 개인별 학습 카드·선택형 활동 |

> 📌 **활용 방법 요약**
> - 칼럼 주제로 직접 활용: "핀란드는 왜 위험한 놀이를 시킬까" → 숲 학교·위험한 놀이 참고
> - 수업 설계 참고: 어떤 교육법으로 수업을 짤지 연결 역량 보고 결정
> - 태그 연결: "연결 역량" 컬럼 → 축 1 역량 태그로 바로 연결
> - 과목 연결: 연결 역량 → 과목·분야 분류표 → 축 3 과목 태그로 연결
