# 바른 교육 칼럼 — 고민 시리즈 ("이런 아이 어떻게 해요?")

> 방과후 강사들의 실제 고민을 선배 강사 시선으로 풀어주는 실전 가이드
> "별거 아니야, 이렇게 하면 돼" — 경험 많은 강사가 옆에서 알려주는 느낌으로

---

**주제 목록**
수업 방해하는 아이 / 참여 안 하는 아이 / 감정 조절 안 되는 아이 / ADHD 의심 아이 / 느린 학습자 / 무기력한 아이 / 스마트폰·게임 중독 아이 / 분리불안 아이 / 다문화·언어 장벽 아이 / 학부모가 더 문제인 경우 / 과잉 경쟁하는 아이 / 틱장애 아이 / 선택적 함구증 아이 / 애착 결핍 아이 / 가정폭력·방임 의심 아이 등

**⚠️ D 시리즈 작성 시 반드시 준수**
- 진단명 단정 금지 → "ADHD인 아이" ❌ "집중이 어려운 아이" ✅
- 실제 사례처럼 쓰지 않는다 → 일반적 상황으로 서술
- 단정적 표현 금지 → "이렇게 해야 한다" ❌ "이런 방법을 시도해볼 수 있다" ✅
- 전문가 영역(심리·의료·법)은 "전문가 상담을 권장한다"로 마무리
- 학부모·아이 비난 뉘앙스 절대 금지
- 강사를 해결사로 묘사하지 않는다
- 각 칼럼 하단 면책 문구 삽입: "본 내용은 현장 경험을 바탕으로 한 일반적 정보이며, 전문적인 심리·의료 상담을 대체하지 않습니다"
